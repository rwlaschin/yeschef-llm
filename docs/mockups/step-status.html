Step Status

dashboard/components/StepStatus.vue — one-word status label for a plan/step run. Plain capitalized text, no background/pill; color alone carries the state. Exactly four states + fallback.

status="pending" (message sent, not started)

pending

status="running" (LLM handling)

running

status="success" (done, passed)

success

status="fail" (error / abort / FAIL — reason lives in outcome field, not shown here)

fail

status=(unrecognized) — falls back to pending/muted treatment

whatever

Typical usage — dense inline run list; a "not included in results" run is represented by the PARENT block's reduced opacity, not a fifth status
